Addis Eats - Static MenuThis is a quick front-end menu built for Addis Eats. 
It's a static React project set up with Vite to practice using JSX, passing props, and mapping components.  
How to run it? 
- Install the project dependencies by running npm install.  
- Start the local development server with npm run dev.  
- Open the local URL provided the terminal (http://localhost:5174/).
